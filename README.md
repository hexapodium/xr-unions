# Group grid

`public/group-grid.js` renders Markdown supplied in the `groups` attribute of
`<group-grid>`. It includes its own CSS. The only published files are the
script, `public/icons/`, and `public/index.html` (a small component preview).
No documents, Markdown drafts, JSON caches, or Airtable credentials are served.

**Squarespace:** Paste `squarespace/group-grid-inline.html` into a Code Block.
This is the **recommended** snippet: it is generated by
`npm run build:inline` and inlines `public/group-grid.js` directly, so the
grid keeps working even when GitHub Pages is unpublished, down, or the repo
moves. Group icons stay remote URLs, and any icon that fails to load falls
back automatically to a letter placeholder, so a dead icon never breaks a
tile.

`squarespace/group-grid-snippet.html` loads the component over the network
instead of inlining it, so use it only when you want updates to the script to
reach the live page without re-pasting. After changing content or
`public/group-grid.js`, re-run `npm run build:inline` and re-paste the inline
snippet.

**Content source:** `npm run build:inline` prefers a root `groups.md` if one
exists, falling back to the Markdown already embedded in
`squarespace/group-grid-snippet.html`. `groups.md` is plain Markdown, so it
may contain literal double quotes and `&` — the build HTML-escapes them for
the attribute. It carries no `icon:` lines, so icons are re-attached by group
name from the snippet; groups that already declare an icon keep theirs. Commit
`groups.md` if you want CI to reproduce the same snippet (the staleness test
skips itself when it's missing).

Edit the Markdown in whichever source you use; sections start
with `##`, groups with `###`, optional icons use `icon: https://...`, and
collapsible blocks start with `+++`. Icons must use published URLs with exact
case. Double quotes are only a problem in the hand-edited snippet (use single
quotes there); `groups.md` has no such restriction.

**Google Docs drafts:** Export group documents as `.docx` into `wcpwriteups/`
(ignored by Git), run `npm ci`, then `npm run parse-wcpwriteups`. This creates
`.generated/groups.md` for review and hand editing, plus an intermediate JSON
file; both stay outside `public/` and are ignored by Git. Copy edited Markdown
into the Squarespace Code Block; this does **not** update the live snippet
automatically. `drafts/groups.md` holds the earlier conversion for reference;
running the parser never overwrites it or the hand-edited snippet. Airtable
view links in the documents remain links, not expanded records.

Run `npm test` for the grid data check; it also verifies that
`squarespace/group-grid-inline.html` is in sync with its sources and carries
no external script dependency. Serve `public/` with a local static
server; the preview page can load either Squarespace snippet or a Markdown
draft without publishing any of them. GitHub Pages publishes `public/` from
`main` on push; this `group-grid` branch does not change the live site until
merged. The `expandos` branch retains the previous Airtable/expando experiments.
