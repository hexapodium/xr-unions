Guide to writing groups definitions for the WCP groups index

Everything is in a markdown-derived format:

  • normal formatting like bold and italic work
  • Links work as normal - you MUST include a http:// or https://
  • Bullets work with a -

extras!

Top level headings (like 'PCS Green Workplaces') come in at level 2 - prefix with ##

## like this

each group is then at level 3 with a ###

### like this

Follow each header line with 'icon:some-url.jpg' to point to a group icon: all the initial set are hosted on hexapodium.github.io/xr-unions/icons/ - note that these are case sensitive!

### IWGB Game Workers
icon:hexapodium.github.io/xr-unions/icons/IWGB_GW.png

Normally you follow this with a short text summary

IWGB are a bunch of [cool folks](http://iwgb.org.uk) with a [videogames branch](https://www.gameworkers.co.uk/) who are currently smashing it in their recognition fight

and then the first normal subhead:

**Key group activities**
- They're unionising videogames, a historically labour-abusive industry
- the rockstar fight has a load of comrades in it

You can do any normal subheads you like

**Ways the IWGB are cool as heck**
- hardcore
- some have excellent beards
- red dead was actually pretty good

then expandable links come on a +++

+++ relevant docs
- [list item 1](http://some.place)
- [list item 2](httpL//example.com)
- these don't all have to be links
- they can also have **formatting**

Rinse and repeat for additional docs. There's a playground/tester at hexapodium.github.io/xr-unions - this page! - which you can use to see some example markdown (hit f12) and load your own markdown without having to edit the site directly.
